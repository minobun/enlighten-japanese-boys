# public/character/

ずんだもんの立ち絵画像を置く場所(docs/spec.md §13 / Issue #18)。

このディレクトリの中身は `.gitignore` でコミット対象外(この README のみコミット)。
画像の用意(PSD からの書き出し)はリポジトリオーナーが行う。

## 想定素材: 坂本アヒル氏の PSD 立ち絵

坂本アヒル氏のずんだもん立ち絵 PSD のようなレイヤー分けされた素材から、
**体(口以外を統合したもの)と口レイヤーを別々の PNG として、同じキャンバスサイズで
書き出して**使う。キャンバスサイズが同じなら、コード側は2枚を同じ位置に重ねるだけで
位置合わせが不要になる。

書き出す PNG(表情1つあたり):

| ファイル | 内容 |
| --- | --- |
| body | 口レイヤーを全て非表示にして、残り(体・顔・目・眉など)を統合したもの |
| mouth.closed | 口を閉じた口レイヤーのみ(体は非表示) |
| mouth.open | 口を開いた口レイヤーのみ(体は非表示) |

いずれも**元 PSD と同じキャンバスサイズのまま**(トリミングしない)書き出すこと。

## 利用前チェックリスト(必須)

- [ ] 使用前に VOICEVOX / ずんだもん(東北ずん子・ずんだもんプロジェクト)の最新の利用ガイドラインを確認した
- [ ] 立ち絵素材(坂本アヒル氏の PSD 等)の利用条件を確認した

- [ ] 素材画像本体はコミットしていない

## 置き方

固定ファイル名ではなく、`content/{id}.json` の `character` フィールドでファイル名を指定する
(bgm と同じく、コード側にファイル名を決め打ちしない)。

表情は3種類まで(`normal` は必須、`troubled` / `angry` は任意)。口パクさせる表情は
`body` + `mouth`(closed/open)で、口パクさせない表情は文字列1つで書く。

```json
"character": {
  "enabled": ["outro"],
  "normal": {
    "body": "normal_body.png",
    "mouth": { "closed": "mouth_closed.png", "open": "mouth_open.png" }
  },
  "troubled": {
    "body": "troubled_body.png",
    "mouth": { "closed": "mouth_closed.png", "open": "mouth_open.png" }
  },
  "scale": 1
}
```

- `enabled`: 立ち絵を出すかどうか。**省略時は `false`(出さない)**。設定を消さずにオン/オフを
  切り替えられるようにするためのフラグ
  - `true` / `false`: 全シーン一括
  - `["hook", "item", "outro"]`: 出すシーンだけを選ぶ。例えば `["outro"]` なら
    まとめだけにずんだもんが出る(ep01 はこの設定)
- `normal`: 必須。ベースの表情
- `troubled`: NGを指摘している間に使う表情(任意)
- `angry`: `troubled` が無い場合の代替(任意)
- `scale`: 表示サイズの倍率(省略時は1)
- 各表情の `mouth` は任意。省略すると口パクせず `body` の1枚が静止表示される
- 口レイヤーが表情間で共通なら、同じファイルを複数の表情から指定してよい(上の例)
- レイヤー分けされていない1枚絵しか無い場合は、文字列1つ(例: `"normal": "zundamon.png"`)でもよい(口パクなし)

表情は揃っていなくてもよい。「`normal` のみ」でも動作する
(揃っていない表情はフォールバック順どおりに `normal` が使われる)。

## 表示位置

Hook / Item では右下、まとめ(Outro)では**中央**に置かれる(まとめはずんだもんに
喋らせる画にするため)。位置とサイズは `src/theme.ts` の `character` トークンで調整する。

`normal` の body に対応する画像ファイルが置かれていない場合は、警告ログを出すだけで
立ち絵なしのままレンダリングされる(レンダリングは通る)。口レイヤーのファイルが
無い場合はその口レイヤーだけスキップされる。

## クレジット表記

素材のクレジットが必要な場合は、`content/{id}.json` の `credits` フィールドに書けば
`scripts/description.ts` が概要欄に自動で追記する(docs/spec.md §12 / Issue #14)。
